## Cosa fa Macaron

Macaron trasforma un computer macOS in una workstation remota temporanea. Abilita l'accesso SSH, impedisce la sospensione, avvia Tailscale e lancia i servizi configurati. Quando si ferma, arresta i servizi e ripristina le impostazioni di sistema precedenti.

<CardGrid>
  <Card title="Parti in pochi minuti" icon="rocket">
    Installa un unico binario precompilato, esegui `macaron` e collegati usando l'indirizzo Tailscale mostrato nel terminale.
  </Card>
  <Card title="Usa i tuoi servizi" icon="server">
    Qualsiasi applicazione può diventare un servizio aggiungendo una piccola directory `.macaron` con uno script di avvio in foreground.
  </Card>
  <Card title="Privato per scelta" icon="padlock">
    SSH e gli URL dei servizi usano la rete Tailscale privata, senza esporre porte su Internet.
  </Card>
</CardGrid>
